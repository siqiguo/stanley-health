## 建议训练结构

- 每周 3–4 次轻松跑，心率以 135–148 bpm 为主。
- 每周最多一次质量课，在节奏跑与短间歇/变速跑之间二选一。
- 两次高强度训练至少间隔 48 小时。
- 周跑量维持约 25–30 km；增加距离时单周增幅尽量不超过约 10%。
- 每周安排 1–2 次臀桥、深蹲、弓步和提踵等基础力量训练。

以上区间由当前样本归纳，并非医学诊断或实验室心率分区；出现胸痛、明显头晕、异常气促或心悸时应立即停止运动并就医。
